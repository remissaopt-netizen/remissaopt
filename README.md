# Remission to the Nation 🏛️

Portal Oficial do Programa Nacional de Remissão Financeira, Anistia de Dívidas e Restauração de Crédito.

## 🚀 Funcionalidades
- **Simulador Interativo de Remissão**: Cálculo em tempo real com descontos de 85% a 95% em dívidas bancárias, comerciais e fiscais.
- **Consulta de Protocolo**: Formulário de consulta de CPF/CNPJ com integração direta via WhatsApp.
- **Design System Glassmorphic Premium**: Cores ouro imperial, dark mode, animações dinâmicas e contadores estatísticos em tempo real.
- **Responsivo & SEO**: Otimizado para dispositivos móveis, com meta-tags OpenGraph e estrutura semântica HTML5.
